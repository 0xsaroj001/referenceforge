# Season II Provider submission checklist

Deadline: 1 December 2026 23:59 UTC / 2 December 05:29 IST. Source: [official rules](https://hackathon.telegraphprotocol.com/rules), Provider selection. Current status: preparation, not submitted.

## Entry and identity

[ ] Official H2 registration confirmed with receipt; named track Miners / Providers.
[ ] Team/contact and related wallets/groups disclosed accurately.
[ ] Published country, identity, tax and prize-payment eligibility checked.
[ ] Concrete Intents, owned current V2 registration and chosen mission relevance recorded.
[ ] Original contribution and material reused components/licenses disclosed.

## Working contribution

[ ] Current endpoint/reviewer access and V2 descriptor can be independently exercised.
[ ] Each claimed pair passes its full relevant task, source, unit, scope and failure cases.
[ ] Independent same-Intent quality evidence supports the 24/35 technical minimum.
[ ] Honest availability/capacity/latency/cost evidence is included.
[ ] Mission impact is independently repeatable through accepted tests or real app workflows.
[ ] H2 activity/transaction evidence is from the event period.

## Packet

[ ] Project/team/track details, exact Intents and working link.
[ ] 2–5 minute demo or accessible equivalent.
[ ] Beginner-friendly setup, prerequisites/configuration and a new sample input/result.
[ ] Network and deployment stated; costs/spending limits, maintenance and known constraints.
[ ] Traceable test/source versions, delivery/routing/accounting records where claimed.
[ ] Useful public summary with a Try/Use/Connect/Build/Compete link.
[ ] Explicit owner choices for public assets, Anjoman material and buyer introductions.
[ ] Private research, credentials, customer data and protected evaluation material excluded.
[ ] Official H2 final submission completed and receipt archived locally.

## Optional consumption evidence

[ ] Qualifying H2 mission app identified; independent operator groups counted once.
[ ] Three meaningful executions with different inputs and qualifying use on two UTC dates.
[ ] Applicable ranked-routing proof for ranked-route points.
[ ] Matched delivery identity plus verified cost/spend/payment accounting.
[ ] No duplicate request counts, collusive traffic or fake independent-user claims.

A local checkbox, Explorer rank or score estimate is not an award or submission receipt. December challenges require a separate qualifying entry.
